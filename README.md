## 🚀 How to Run

Clone the repo:

```bash
git clone https://github.com/abdulkid802-creator/projects.git
cd projects
```

**Python** — no dependencies, just Python 3:
```bash
python python/"RPG Battle Game 2.py"
```

**Java** — compile and run:
```bash
cd Java
javac BankAccount.java
java BankAccount
```
